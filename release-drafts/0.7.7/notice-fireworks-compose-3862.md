kuilt [v0.7.7](<v0.7.7 release link>) gives L5 a third answer to "device id or account id?": a **device key** (tractat-us/kuilt#3159). It is stable across every surface a device reaches, and a peer can check it.

Each device keeps one P-256 key in `DeviceKeyStore.platform(…)`: the Keychain on iOS, the Keystore on Android, IndexedDB on wasm. A room member proves it on every join. Give the nw and server factories the same store, and `Member.key` is the same `DidKey` in both rooms. `DeviceIdStore` stays f-c's own id, as ruled: pass it as `join(…, deviceId =)` and the key signs over it, so `Member.identity.deviceId` is bound to `Member.key`.

What that buys L5, and what it doesn't:

- **One device, N reaches: yes.** Merge `LobbyPlayer` rows on the key. Ranking `Nw` over `WebSocket` still needs the per-seam liveness from the 2026-07-30 comment; 0.7.7 adds none.
- **A key in `LobbyPresence` is still only a claim.** Presence is f-c's CRDT, not a kuilt roster. Trust it only once it matches a `Member.key` the room checked, or sign the entry with `DeviceKey.sign` under an f-c domain tag and check it with `DidKey.verify`. Never sign bytes without your own tag in front.
- **One person: no.** A person with two devices has two keys. Linking them is later work in kuilt, so the account stays the person-level id.
- **Keys aren't unique per row.** Two wasm tabs share one key and hold two seats; dedupe for display, not for routing.

Two more things the upgrade brings:

- `RejoinCoordinator`'s KDoc says a cold start "cannot present a kuilt `ResumeToken`". From 0.7.7 it doesn't have to: a restarted device gets its held seat back by its key, and inside its pass it skips vetting. It still has to use a platform store, not `InMemoryDeviceKeyStore`.
- **The wire breaks.** A 0.7.7 server refuses a 0.7.6 app with `ProtocolMismatch`, and the reverse. Shipped iOS builds can't join an upgraded server, so plan the server and app rollout together. f-c pins `0.7.0-dev.1700`, so the jump takes in 0.7.1–0.7.6 too. Migration steps are in the release notes.
