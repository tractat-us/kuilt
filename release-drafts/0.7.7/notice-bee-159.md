For the record: kuilt [v0.7.7](<v0.7.7 release link>) makes a kuilt `Room` member come back as itself after a drop or a restart, by a device key it proves on every join (tractat-us/kuilt#3159). It does not replace this PR's kept identities. An HTTP-joined agent is not a `Room` member, so its return still runs through `KeptIdentities`. The two rules agree, though: a credential many people hold, like the join link's key, never resumes in either. Details in #149.
