# Agent-facing capability discovery — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Give downstream AI coding agents a way to discover that kuilt already provides a primitive (reconnect/resume, CRDTs, liveness, consensus, dedup) instead of hand-rolling it — via a symptom→primitive cookbook plus a Claude Code skill that routes to it in the consumer's own vocabulary.

**Architecture:** Two artifacts live in kuilt (source of truth, versioned with the library): (1) `docs/agent-cookbook.md`, an intent-indexed reverse index whose code snippets are verbatim-cited from compiled functions; (2) `.claude/skills/kuilt-primitives/`, a skill whose `description` enumerates the *consumer's* problem vocabulary (rejoin/table/seat/…) and whose body routes to the cookbook. A CLAUDE.md rule keeps both in sync as the API moves. Four genuine missing-primitive gaps found by the survey are filed as issues, not cookbook rows.

**Tech Stack:** Kotlin Multiplatform, Gradle, Dokka/Writerside docs conventions, Claude Code skills (markdown + YAML frontmatter), `gh` for issues.

## Global Constraints

- **Do not touch the accessible-first published surfaces** — Writerside guide landing, README opening, the `docs/warp-vision.md`-style descent. This is a *new, third surface*.
- **Anti-rot = verbatim citation, not `@sample`.** `docs/agent-cookbook.md` is plain markdown; Dokka `@sample` does not apply. Every code block is copied verbatim from a compiled function (a `commonSamples` sample or a `commonTest` test) and carries an HTML comment `<!-- verbatim from <path>#<symbol> -->`, exactly like the Writerside `crdt-*.md` topics.
- **`explicitApi()` is enforced.** Any new sample function is `public` (or lives in a `commonSamples`/`commonTest` source set where the convention applies) and compiles under the standard target set.
- **Cite real symbols only.** Never invent an API. If you don't know a type's exact signature, read the type's source and its existing tests before writing a snippet; the snippet must compile.
- **Use `detektAll`, not bare `detekt`.** Docs-only changes skip the heavy build in CI, but any change that adds a `commonSamples`/`commonTest` function triggers the full `./gradlew build`.
- **Branch from `origin/main`.** `git fetch origin main && git checkout -b <branch> origin/main`. Changes go through a PR; auto-merge once `ci-required` is green.
- **AI attribution** on the gap issues: prefix each issue body with `> 🤖 This comment was generated by Claude on behalf of @keddie.`

- `docs/agent-cookbook.md` — **new.** The cookbook. Top matter (one plain-language paragraph + the "don't build this yourself" tripwire list), then one section per capability area, each a table of intent→primitive rows with a verbatim-cited snippet.
- `kuilt-*/src/commonSamples/kotlin/us/tractat/kuilt/<module>/AgentCookbookSamples.kt` — **new, per module that needs a fresh snippet** (only where no existing compiled snippet is citable). Minimal `public` sample functions the cookbook quotes.
