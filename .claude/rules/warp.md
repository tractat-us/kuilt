# Warp

Instead of one machine doing every job, a pile of work can be spread across
whoever happens to be connected right now, with no single boss handing it out
and no risk of two devices doing the same job twice. These modules are that
scheduler, the walled-off sandbox that safely runs code a peer sent you, the
pieces that plan and measure how the work gets shared out, and devices learning
one shared model together without any of them handing over their own data.

What a consumer is about to hand-roll, and the primitive that already exists, with
compiled snippets: `docs/agent-cookbook/warp.md`. This file holds only the
rules for changing the code here.
